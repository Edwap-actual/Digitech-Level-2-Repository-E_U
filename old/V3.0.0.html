Confidentiality

A compromised password could result in unauthorised users acquiring access.

Confidentiality means keeping information private and preventing unauthorised people from accessing it. Strong, unique passwords help protect personal information by making it harder for attackers to gain access to accounts.

Integrity 

If an account is breached, information, settings or content may be changed.

Integrity means ensuring that information remains accurate and has not been changed by someone without permission. Protecting accounts with strong passwords helps prevent unauthorised users from altering information.

Availability

A solution must be easy to implement, and even easier to use.

Availability means that any cybersecurity technique or program implemented must be easy enough for the correctly authorized user to use, as to maintain the security of the account, and its availability to the user.

Password Strength

What makes a password truly secure?

Length

Longer passwords hold more possible combinations of characters, which makes them harder to guess. The ideal password should be 16+ characters. A long passphrase can be easier to remember, while maintaining the ideal length.

Uniqueness

Avoid using the same passwords across multiple accounts. If one reused password is breached, then multiple other accounts are put at risk. Do not use common passwords such as; "password", "1234", "abc123", or "admin". 

Randomness

Predictable passwords are easy to guess. Avoid common passwords, patterns and predictable character substitutions. Either go for a randomly generated password, or a random passphrase. Both of these give a lesser chance of your password being predicted. 

Avoiding Personal Information

Passwords should not be based on easily accessible personal information, such as birthdays, pets, family members or favourite sports teams. Personal information can make a password easier to predict.

Why Does Password Strength Matter?

Attackers can attempt to guess passwords using automated systems. A weak, or predictable password may be much easier to guess than a long, unique, and unpredictable one. The difficulty of attacking a password also depends on factors such as the authentication system, password storage method, and the available computing resources.

Creating a Strong Password

Do

  • Use a long password or passphrase
  • Use a unique password for each account
  • Use randomly generated passwords where appropriate
  • Use a password manager to store password
  • Use multi-factor authentication (MFA)

Do not

  • Use common passwords
  • Reuse any passwords
  • Use personal information to form a password
  • Create new passwords in a predictable patter
  • Share your passwords with other people
